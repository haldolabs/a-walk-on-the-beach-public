# a walk on the beach — pictures

Screenshots of [*a walk on the beach*](https://synapticon.itch.io/beach-walk), kept here so the
itch.io page can show them. The game's source is in a private repository; this one holds only
images.

Images under `shots/` are © Haldo Labs. The scenes in them use coastlines © OpenStreetMap
contributors, land from Natural Earth, stars from the Yale Bright Star Catalogue, constellation
figures from d3-celestial by Olaf Frohn, and NASA's map of the moon.
